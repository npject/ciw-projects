# PHP User System


## Description

A simple PHP project for user authentication and profile management.


## Features

- Login and register
- User profile and edit
- Products page
- API-based user action


## Technologies

- PHP
- MySQL
- PHP Sessions
- JavaScript
- Fetch API
- LocalStorage
- HTML / CSS
- Bootstrap 5
