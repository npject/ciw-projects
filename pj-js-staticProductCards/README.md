# Static Product Cards


## Description

A simple project that displays product cards using JavaScript.
Products are stored in a static array and rendered on the page.


## Features

- Render product cards dynamically
- Display product title and image
- Simple card layout 


## Technologies

- HTML
- CSS
- JS
