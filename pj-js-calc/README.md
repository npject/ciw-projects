# Simple Javascript Calculator


## Description

This is a simple calculator build with HTML, CSS and JavaScript.
This project is created to practice basic javascript logic and DOM manipulation.


## Features

- Add, subtract, multiply and divide numbers
- Clear input value 
- Simple and clean UI


## Technologies

- HTML
- CSS 
- JS

## How to Run

Just open `index.html` file in your browser.
