# Mini Shop 


## Description

A simple mini shop project built with JavaScrip.
Products are fetched from an API and displayed on the page.


## Features

- Fetch products from API
- Products list page
- Single product page
- Add to cart with localStorage
- Cart page


## Technologies

- JavaScript
- Fake Store API
- LocalStorage
- HTML
- CSS
- Bootstrap 5
