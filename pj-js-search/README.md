# Simple JavaScript Search


## Description

A simple search project build with JavaScript.
It filters a list of items based on user input.


## Features 

- Live search
- Case-insensitive filtering
- Simple list UI


## Technologies

- HTML
- CSS
- JS


## Project Structure

📁pj-js-search/
├── 📁assets/

│   │   └── 📄style.css
│   └── 📁js/
│       └── 📄main.js
└── 📄index.html


## How to Run

open `index.html` in your browser.


## Note 

This project is created to practice DOM manipulation and basic Javascript logic.
