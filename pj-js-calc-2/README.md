# Simple Javascript Calculator (Eval Version)


## Description 

A very simple calculator build with HTML, CSS and JavaScript.
This version uses `eval()` to calculate expressions and is made only for practice.


## Features

- basic math oprations
- clear input value
- minimal UI


## Technologies

- HTML
- CSS
- JS
